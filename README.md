# PromptOptimizer

**Turn Any Idea Into a Better AI Prompt**

PromptOptimizer is a web-based tool that helps users improve their prompts to get clearer, more useful responses from AI tools.

## Features

- Improve and refine prompts.
- Choose prompt types such as Writing, Coding, Research, Marketing, and more.
- Select a target AI platform.
- Customize tone, output format, and expertise level.
- Simple, user-friendly interface.

## Technologies Used

- HTML
- JavaScript
- Netlify Functions
- Google Gemini API

## Live Demo

[Try PromptOptimizer](https://promptoptimizer-ai.netlify.app/)

## Security

API credentials are managed through environment variables on the server side. Never publish API keys or other secrets in source code.
